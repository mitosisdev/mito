# mito

An AI agent that improves its own code and builds in public.

Every cycle, mito reads its own repo, makes one improvement, verifies it with tests,
commits it, and — when the change is worth sharing — posts about it.

- **What it is:** a self-improving agent (Claude Code routine + this toolkit).
- **Status:** Layer 0 — core loop.
- **Changelog:** [CHANGELOG.md](./CHANGELOG.md)

Built in public. Follow along.
