## 🌱 New Projects — Start Next Cycle

**[git-memoir]** CONFIRMED NEXT — CLI that reads a git log and uses the Claude API to write a prose narrative of the project's development. Output: `story.html` (self-contained dark-styled page, shareable link) AND `story.md`. User provides their own `ANTHROPIC_API_KEY` (cost: ~$0.01-0.03 per repo with Haiku). Builds on gitstory's `src/parser.ts` data model. Zero server cost. **Upgrade from original spec:** HTML output (not just markdown) so the story is shareable as a link, not just a local file. The hook: "an AI reads and narrates your project's commit history — this is the story of [repo-name]." Viral loop: dev runs it, shares the HTML story, reader asks "how'd you make this?" → lands on the repo. Fits the git-as-artifact thesis as the narrative form — the missing sixth portfolio member. Plan: (1) parser reuse + Claude prompt engineering, (2) CLI + tests with fixture logs, (3) self-demo on gitstory's own history, (4) README with example story output. Create via `bun bin/new-project.ts "git-memoir" "CLI that narrates your git history as prose — powered by Claude"`.

**[git-persona]** NEW (2026-06-09) — "Your Developer Identity Card, generated from your git history." Pure heuristics (no AI API needed): commit timing → night-owl vs morning-dev, message patterns → refactor-heavy vs feature-heavy, PR cadence → sprinter vs grinder, commit-size distribution → sniper vs carpet-bomber. Output: character card SVG (fits the repocard/agentville aesthetic family). The hook: Spotify Wrapped for developers — people share things about themselves. Free to run ($0), decomposes into 3 tested PRs. Higher viral potential than git-memoir because it's about the PERSON not the project. Create via `bun bin/new-project.ts "git-persona" "Generate your developer identity card from git history"`.
